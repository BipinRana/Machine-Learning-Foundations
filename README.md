# Machine Learning Projects

This repository consolidates several of my earlier machine learning and data-processing repositories into a single location. The projects were originally developed as separate repositories while I was learning different parts of the machine learning workflow, from preprocessing and implementing algorithms from scratch to distributed data processing with PySpark.

The original repositories have been preserved and are linked below for reference.

## Repository Structure

```text
.
├── learning-machine-learning/
├── preprocessing-and-modeling/
└── pyspark/
```

### `learning-machine-learning/`

Experiments and implementations created while learning fundamental machine learning concepts and algorithms.

Original repository:
[LearningMachineLearningFromScratch](https://github.com/BipinRana/LearningMachineLearningFromScratch)

### `preprocessing-and-modeling/`

Exercises and implementations related to data preprocessing, feature preparation, and basic machine learning modeling workflows.

Original repository:
[PreprocessingBasics](https://github.com/BipinRana/PreprocessingBasics)

### `pyspark/`

Work related to Apache Spark and PySpark, including distributed data processing and machine learning exercises.

Original repository:
[PySpark](https://github.com/BipinRana/PySpark)

## Why Consolidate?

These repositories cover closely related areas of my machine learning learning process. Consolidating them makes the work easier to navigate and provides a clearer view of my progression across:

* data preprocessing and preparation,
* implementation of machine learning concepts,
* model development and experimentation, and
* distributed processing using PySpark.

The individual project directories retain their respective code and development history.
